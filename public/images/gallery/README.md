# Photos de la galerie

Le site affiche automatiquement une photo si elle existe dans ce dossier. Tant
qu'aucune photo n'est ajoutée, un visuel de remplacement (couleur + emoji)
s'affiche à la place — le site reste donc utilisable sans aucune image.

## Comment ajouter une photo

1. Prenez une photo de la réalisation (format paysage, ex. 800x600px, fond clair).
2. Nommez le fichier exactement comme indiqué ci-dessous (en `.jpg`).
3. Déposez le fichier dans ce dossier `public/images/gallery/`.
4. C'est tout — la photo apparaît automatiquement sur le site, à la place du
   visuel de remplacement.
